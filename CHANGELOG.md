# Changelog

## 0.1.1

### Added

- Unsigned macOS DMG (ad-hoc signature) built in CI — right-click → Open to run.
- SHA256SUMS.txt published with every release.
- Sidebar and titlebar brand marks (badger logo + tagline).

### Changed

- Bumped the app version to `0.1.1`.
- Dropped the AppX target (needs a paid Store certificate; NSIS covers Windows).

## 0.1.0

### Added

- Initial Badger release: X/Twitter cleanup (posts, replies, media, highlights, unlike, unfollow) with date, keyword, reply-target, engagement-ceiling, and skip-pinned filters.
- Browser-native login overlay, username auto-detection, JSON run logs, and results browser.
